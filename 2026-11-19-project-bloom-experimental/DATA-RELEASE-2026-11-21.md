# Project B. Experimental: full data release (Nov 21, 2026)

Everything we hold for the Project B. Experimental flight of November 19, 2026 (launched from the
Old Settlers Park RC field, Round Rock, Texas; payload landed west of Bryan, Texas). Files published
earlier in this folder are unchanged.

| Folder | Contents |
|---|---|
| `eagle-flight-computer/` | Eagle flight computer raw log and cleaned CSV (earlier), plus the sounding (CSV/JSON) and column docs |
| `derived/` | Ascent/descent rates (CSV) and ground tracks (GeoJSON and KML) for the Eagle and the KE9CFY-11 tracker |
| `aprs-tracker/` | KE9CFY-11 APRS packets: SondeHub raw, decoded positions (JSON/CSV), stations heard |
| `predictions/` | Full pre-flight Tawhiri prediction and ensemble runs |
| `tracking/` | APRS tracking summary, SPOT Trace STOP fix, Eagle summary |
| `media-metadata/` | Technical metadata for the flight photos and videos |
| `charts/` | SVG charts (earlier) |

Peak altitude: 98,717 ft (30,089 m) from the Eagle flight computer GPS. The KE9CFY-11 tracker's highest
packet was 98,325 ft and its lowest temperature -54 C; those are tracker readings.

Data Hub: https://www.midwestsds.com/msds-data-hub.html#past-flights  
Sounding viewer: https://www.midwestsds.com/soundings/2026-11-19-project-b-experimental.html  
Flight page: https://www.midwestsds.com/project-bloom-experimental.html

Not included: third-party listener records with contact details, scraped web pages, and internal scripts.
