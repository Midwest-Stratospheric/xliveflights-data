# Project B. Experimental: pre-flight predictions

Tawhiri (GFS) predictions run before the flight.

| File | What it is |
|---|---|
| `tawhiri-prediction-2026-11-19.json` | Nominal prediction runs (by burst altitude) with full trajectories and assumptions |
| `tawhiri-ensemble-2026-11-19.json` | Ensemble scenarios (launch-time, burst and rate offsets) with trajectories |
| `tawhiri-ensemble-summary-2026-11-19.json` | Ensemble summary and table |

Reverse-geocoded street addresses and place names were removed from these copies; coordinates, times and
distances are unchanged. The compact `../tawhiri-prediction-summary.json` and `../tawhiri-ensemble-table.csv` were published earlier.
